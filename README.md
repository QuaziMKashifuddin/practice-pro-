## 💰 Personal Expense Tracker

A sleek, functional web application to manage your finances. This tool allows users to track income and expenses in real-time with data persistence.

### ✨ Features
*   Real-time Calculations: Automatically updates your total balance, income, and expense summaries.
*   Data Persistence: Uses `localStorage` to keep your transactions saved even after refreshing the browser.
*   Dynamic UI: Clean, responsive design with color-coded transactions (Green for Income, Red for Expenses).
*   Currency Formatting: Professional financial display using the JavaScript `Intl.NumberFormat` API.
*   History Management: Easily add new entries with decimals or delete past transactions with a single click.

### 🛠️ Tech Stack
*   HTML5 - Semantic structure with custom number validation.
*   CSS3 - Modern layout using Flexbox, CSS Grid, and custom scrollbars.
*   JavaScript (ES6) - Functional array methods (`filter`, `reduce`, `map`) and DOM manipulation.


### 🚀 How to Use
1. Enter a description (e.g., "Grocery Shopping").
2. Enter the amount (use *negative numbers* for expenses, e.g., `-50.00`).
3. Click "Add Transaction" to see your balance update instantly!
